========================================
PROTECTING YOUR PAGES
========================================

Add this to the top of any PHP page:

<?php
require_once dirname(__FILE__) . '/config/auth_middleware.php';
AuthMiddleware::requireLogin();
$user = SessionManager::getUserData();
?>

For admin-only pages, also add:
<?php AuthMiddleware::requireAdmin(); ?>

========================================
HOW THIS SYSTEM WORKS
========================================

User Login Process:
1. User visits login.php
2. Enters username & password
3. Form submits to process_login.php
4. LoginHandler verifies credentials
5. If correct:
   - Session is created
   - Session ID is regenerated
   - User redirected to dashboard
   - Login is logged
6. If incorrect:
   - Failed attempt is recorded
   - After 5 attempts, account locked
   - User shown error message

Session Management:
1. User visits protected page
2. session_handler.php checks:
   - Session exists & is valid
   - Session hasn't timed out (30 min)
   - User is still logged in
3. If valid: Page displays
4. If invalid: Redirects to login

Logout Process:
1. User clicks logout button
2. logout.php destroys session:
   - Clears session data
   - Deletes session cookies
   - Removes session files
3. User redirected to login page

========================================
CREATING NEW PAGES
========================================

To add a new protected page:

1. Create new file (e.g., inventory.php)
2. Add at the top:
   <?php
   require_once dirname(__FILE__) . '/config/auth_middleware.php';
   AuthMiddleware::requireLogin();
   $user = SessionManager::getUserData();
   ?>
3. Now you can safely use:
   - $user['username']
   - $user['first_name']
   - $user['role']
   - etc.

For admin-only features, check:
   if (SessionManager::isAdmin()) {
       // Show admin features
   }
