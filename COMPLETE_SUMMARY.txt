## 🛠️ Configuration

All settings in one file: `config/db_config.php`

```php
// Database
DB_HOST = 'localhost'
DB_USER = 'root'
DB_PASSWORD = ''
DB_NAME = 'inventory_system'

// Session (30 minutes default)
SESSION_TIMEOUT = 1800

// Security (5 attempts, 15 minutes lockout)
MAX_LOGIN_ATTEMPTS = 5
LOGIN_ATTEMPT_TIMEOUT = 900

// Enable for HTTPS production
SESSION_SECURE = false  // Set to true for production
```

## 🤝 Integration with Your Inventory System

### Easy to Add
1. Protect inventory pages with auth check
2. Show user info on inventory pages
3. Log all inventory changes to activity_logs
4. Restrict admin features by role
5. Track who modified what

### Example Integration
```php
<?php
// At top of inventory.php
require_once dirname(__FILE__) . '/config/auth_middleware.php';
AuthMiddleware::requireLogin();
$user = SessionManager::getUserData();
?>

<!-- Now you have secure session -->
Welcome, <?php echo $user['first_name']; ?>

<?php if(SessionManager::isAdmin()): ?>
  <!-- Admin features here -->
<?php endif; ?>
```
